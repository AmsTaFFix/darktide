[size=4][b]Description[/b][/size]
[color=#D4D4D8]Unofficial, temporary bugfix of [url=https://www.nexusmods.com/warhammer40kdarktide/mods/844]"Squad HUD"[/url] by [url=https://www.nexusmods.com/profile/RRMLLNV?gameId=4943]rrmllnv[/url].

Game patch 1.13 broke the teammate combat-ability display in [url=https://www.nexusmods.com/warhammer40kdarktide/mods/844]Squad HUD[/url]: the game removed the old ability-cooldown methods and moved combat abilities to a regenerating resource, so teammate panels stopped showing ability state. This reupload restores it, reads ability buffs safely on teammates, and trims per-frame cost. It changes nothing else. The full list of changes is in the changelog attached to the file.

This build bundles the community fix by LucLeto. Once [url=https://www.nexusmods.com/profile/RRMLLNV?gameId=4943]rrmllnv[/url] updates the original mod, this page is obsolete - please switch back to the original.

[size=4][b]Installation instructions[/b][/size]
[color=#D4D4D8]1. Install and enable [url=https://www.nexusmods.com/warhammer40kdarktide/mods/8]Darktide Mod Framework[/url].
2. Install this archive with Vortex, or extract it into <game>\mods\ so you get <game>\mods\SquadHud\.
3. Make sure "SquadHud" is listed in <game>\mods\mod_load_order.txt.

If you already use the original [url=https://www.nexusmods.com/warhammer40kdarktide/mods/844]Squad HUD[/url], remove it first so you don't run two copies. Your mod settings are kept (same mod id).[/color]

[size=4][b]Main features[/b][/size]
[color=#D4D4D8]Same as the original [url=https://www.nexusmods.com/warhammer40kdarktide/mods/844]Squad HUD[/url]: four compact strike-team panels showing class/status icon, name, total level, teammate distance and coherency, combat ability state, inventory icons (grenade/blitz, ammo, med crate, ammo crate, stimms, expedition salvage), grenade and ammo values, toughness, health, and wounds. An Expanded View key reveals account names, platform icons, and extra details. Everything is configurable in the mod options, and the vanilla squad panels can be hidden to avoid duplicate UI.

This build adds no features - it only restores the mod after patch 1.13.[/color]
