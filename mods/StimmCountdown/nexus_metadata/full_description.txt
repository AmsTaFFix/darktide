[b][size=4]Description[/size][/b]
[color=#D4D4D8]Displays a countdown timer for the Hive Scum (Broker) class stimm ability, showing both the active-effect duration and the cooldown time.

The timer appears next to the stimm slot in the HUD and automatically hides when not needed.

Light green indicates active stimm effect duration; red indicates cooldown time.[/color]


[size=4][b]Installation instructions[/b][/size]
[color=#D4D4D8]1. Install and enable [url=https://www.nexusmods.com/warhammer40kdarktide/mods/8]Darktide Mod Framework[/url].
2. Install this archive with Vortex, or extract it into <game>\mods\ so you get <game>\mods\StimmCountdown\.
3. Make sure "StimmCountdown" is listed in <game>\mods\mod_load_order.txt.

If you already use the original [url=https://www.nexusmods.com/warhammer40kdarktide/mods/653]StimmCountdown[/url], remove it first so you don't run two copies. Your mod settings are kept (same mod id).[/color]


[size=4][b]Main features[/b][/size]
[color=#D4D4D8][list]
[*]Countdown timer next to the Broker stimm syringe slot: active-effect duration, then cooldown.[/*]
[*]Color-coded phases, with per-color overrides for ready, active, and cooldown.[/*]
[*]Optional on-screen notification sound when the stimm comes off cooldown.[/*]
[*]Configurable font type and size, and whether seconds are shown with decimals.[/*]
[*]Exposes a small API other HUD mods (such as Division HUD) can read to show the same countdown in their own layout.[/*]
[/list][/color]
