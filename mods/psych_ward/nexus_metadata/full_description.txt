[size=4][b]Description[/b][/size]
[color=#D4D4D8]Unofficial, temporary bugfix build of [url=https://www.nexusmods.com/warhammer40kdarktide/mods/89]"Psych Ward"[/url] by [url=https://www.nexusmods.com/profile/Fracticality?gameId=4943]Fracticality[/url].

Game updates keep breaking [url=https://www.nexusmods.com/warhammer40kdarktide/mods/89]Psych Ward[/url] in new ways. This page tracks and fixes those bugs as they turn up, changing nothing else - see each version's changelog (Files tab) for exactly what it fixes.

[size=4][b]Installation instructions[/b][/size]
[color=#D4D4D8]1. Install and enable [url=https://www.nexusmods.com/warhammer40kdarktide/mods/8]Darktide Mod Framework[/url].
2. Install this archive with Vortex, or extract it into <game>\mods\ so you get <game>\mods\psych_ward\.
3. Make sure "psych_ward" is listed in <game>\mods\mod_load_order.txt.

If you already use the original [url=https://www.nexusmods.com/warhammer40kdarktide/mods/89]Psych Ward[/url], remove it first so you don't run two copies. Your mod settings are kept (same mod id).[/color]

[size=4][b]Main features[/b][/size]
[color=#D4D4D8]Same as the original [url=https://www.nexusmods.com/warhammer40kdarktide/mods/89]Psych Ward[/url]: access vendors, the Mission Board, Mortis Trials and the Psykhanium directly from the character-select screen, without loading into the Mourningstar.

This build adds no features - it only fixes bugs that game updates introduced.[/color]
